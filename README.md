# 🎯 CareerPath AI

## Career Aspiration & Skill Gap Analysis System

CareerPath AI is an AI-powered career recommendation and skill gap analysis system designed to help students discover suitable career opportunities based on their academic profile, skills, strengths, and development areas.

The system compares a student's assessed skills with career requirements, ranks suitable careers, identifies skill gaps, and provides a personalized development direction.

---

## 🚀 Project Overview

Choosing the right career can be challenging for students because they may not have a clear understanding of which careers match their current skills.

CareerPath AI addresses this problem by providing a structured, skill-based career recommendation system.

The system follows this process:

**Student Profile → Skill Assessment → Career Matching → Career Ranking → Skill Gap Analysis → Development Plan**

## ⚙️ How It Works

### 1. Student Profile
The student provides academic and background information such as:

- Age
- Degree
- Branch
- CGPA
- Internships
- Projects
- Certifications
- Backlogs

### 2. Skill Assessment

The student assesses their skills based on the available skill categories.

### 3. Career Matching

The system compares the student's skill levels with the required skills for different careers.

### 4. Career Ranking

Suitable careers are ranked according to the calculated skill match.

### 5. Skill Gap Analysis

The system identifies skills where the student's current level is below the expected career requirement.

### 6. Development Plan

The identified skill gaps are converted into development priorities to help the student understand what to improve next.

---

## 🧠 Recommendation Approach

Career recommendations are generated using a combination of:

- Student profile information
- Skill ratings
- Career skill requirements
- Skill matching
- Career ranking
- Skill gap analysis

The system focuses on **skill-based recommendations** rather than requiring students to manually choose a career first.
